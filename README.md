# 高爾夫球賽管理系統 v3.0

這是一個使用 Flask (後端) 和 React (前端) 開發的高爾夫球賽管理系統。系統支援本地部署 (v2.0) 和雲端部署 (v3.0) 兩種模式。

## 系統功能

### 1. 賽事管理
- 創建和管理高爾夫球賽事
- 設置賽事日期、地點等資訊
- 查看賽事歷史記錄

### 2. 參賽者管理
- Excel 批量匯入參賽者資料
- 手動新增/編輯參賽者資訊
- 參賽者列表查看和搜尋
- 參賽者備註功能

### 3. 報到功能
- 參賽者報到/取消報到
- 即時更新報到狀態
- 報到時間自動記錄
- 報到狀態總覽

### 4. 分組功能
- 智能自動分組
- 手動調整分組
- 分組鎖定功能
- 分組狀態即時更新
- 匯出分組圖表

## 部署說明

### 本地部署 (v2.0)
與原有安裝步驟相同：
1. 克隆專案
2. 設置後端（Python 虛擬環境、依賴安裝）
3. 設置前端（Node.js 依賴安裝）
4. 啟動本地服務器

### 雲端部署 (v3.0)

#### 前端部署 (Vercel)
1. Fork GitHub 專案
2. 在 Vercel 中導入專案
3. 設置環境變數：
   ```
   REACT_APP_API_URL=https://your-backend-url.com
   NODE_VERSION=18.x
   ```

#### 後端部署 (Render)
1. 在 Render 創建 Web Service
2. 連接 GitHub 專案
3. 設置環境變數：
   ```
   DATABASE_URL=postgresql://username:password@host:port/database
   FLASK_ENV=production
   FLASK_DEBUG=0
   SECRET_KEY=your-secret-key-here
   ```

## 系統需求

- Python 3.8 或以上
- Node.js 14 或以上
- PostgreSQL (雲端部署) / SQLite (本地部署)
